# Actual nearby places and mobile checkout — 2026-10-06

The default destination flow now searches actual nearby cafes/restaurants using Kakao Maps category search (FD6/CE7, 1 km) and OSM only when the Kakao key is absent. It no longer relocates the three example merchants around arbitrary destinations. Coordinates, addresses, phone numbers and place links come from the search provider. Live cards rank by destination walk distance and verified arrival-window offers; they never manufacture merchant stock, wait, preparation time, menu price, discount or a gift.

Offer inventory: `public/data/merchant-offers.json` (empty until confirmed offers are obtained), or `GET /api/merchant-offers` on a configured server. Each offer requires `placeId`, `verified: true`, `title`, `terms`, `discountPercent`, `validFrom`, `validUntil`; optional `startTime`, `endTime`, `reward`, HTTPS `redeemUrl`. Operational verification/consent must occur before an administrator publishes an entry. A boolean does not verify a merchant by itself. Expired/unverified/wrong-place offers are excluded. An external verified redemption URL is opened directly; the MVP does not charge real shops or issue unconfirmed coupons. Empty inventory means no benefit badge rather than a repetitive negative warning. Kakao place search does not supply merchant discount agreements.

Default live cards open a place sheet with actual address, destination ETA, walking estimate, map route, telephone and Kakao sharing. Demo stores, local checkout and robot synchronization remain only in the explicitly labeled settings scenario. Actual store cards cannot produce a local order masquerading as a merchant order.

Taxi: live OSM Overpass lookup of taxi ranks and named primary/secondary/tertiary roads within 800 m. Bridge/tunnel/no-foot/no-access ways excluded. Road candidates are projected onto real road geometry; they are not certified/legal curb locations. The selection sheet tells users to confirm a suitable sidewalk pickup point. Selection includes the walking estimate in the taxi arrival time; Kakao walking link opens guidance. There is no taxi dispatch API or guaranteed pickup. No guessed Kakao T private endpoint.

Checkout confirmation uses a dark full-screen recipient + amount + cancel/confirm layout, then local-save progress and completion. It includes one readable test-environment label; it never says KakaoPay authenticated or money was sent. Source/provenance text moves to Service Information and collapsed route information, preserving attribution and errors. Scenario state remains labeled.

Verification: Node unit tests cover verified offer eligibility, missing live merchant states, category/destination matching and pickup geometry/unsafe-way exclusion. Mobile regression uses controlled browser API fixtures, separately from production API verification; fixture results must not be described as live feeds.

## Updated MVP presentation scope — 2026-10-06

At the user's explicit request, ordinary live place cards now carry seeded **presentation** gifts or 3–12% cashback and example products/prices/preparation states. `presentationBenefits.js` keeps benefits deterministic by place ID, so changing tabs/filters does not randomly change the promotion. Live place identity/coordinates are preserved; `isPresentation`, `isDemo`, and `offer.isDemo` explicitly distinguish constructed merchant state. The UI has an MVP header mark, Service Information explains the scope, and payment confirmation states no real charge/store transmission. These promotions are not published as merchant-approved agreements or real redeemable cash. Cashback amount is calculated from order total and persisted with local orders; gifts carry to the completion screen. This supersedes the earlier statement that ordinary live cards are browse-only.

Taxi candidates now receive independent distance-based fare, walk and total-time estimates. Recommended mode balances total time, fare, walking and an actual taxi-rank preference. Fare/walk/arrival sort modes really reorder candidates. Price is an MVP comparison model, not a metered fare or a live Kakao quote. Candidate map geometry remains actual OSM; selected pickup feeds human ETA as before.
