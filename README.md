# 당도

목적지를 고르고, 이동 방법과 주변 식당을 확인하고, 카카오톡으로 함께 갈 곳을 공유하는 모바일 웹입니다.

## 현재 화면

- 시작 화면 → 안녕하세요 로그인/프로필 → GPS 연결 또는 위치 직접 선택 → 내 위치의 지도. GPS 성공 후 서비스 아이콘 홈을 거치지 않고 바로 지도로 이동
- 사용자가 선택하는 GPS 연결 또는 목적지 검색. 기본 시작 지역 없음
- 당도 기기 계정 가입·로그인·로그아웃. 닉네임과 프로필 사진은 선택
- 실제 지도·장소 조회, 장소 저장, 카카오맵 길찾기와 카카오내비 목적지 전달
- 목적지 및 식당 카카오톡 공유. 링크를 열면 같은 목적지로 시작
- 데이터가 제공되는 경우 공공 API의 지하철·지역 혼잡도와 추천 계산. 없는 실시간 수치를 생성하지 않음

가상 잔액, 가상 상품, 모의 결제·주문·픽업, 체험 메뉴는 현재 앱 진입 경로와 번들에서 제거했습니다. 과거 계산 모델과 검증 파일은 저장소에 남아 있으나 현재 서비스와 연결되지 않습니다.

## 계정과 서비스 범위

당도 기기 계정은 같은 브라우저에서 사용하는 로컬 계정입니다. 비밀번호를 저장하지 않고 PBKDF2와 AES-GCM으로 프로필을 암호화합니다. 다른 기기 동기화·서버 인증·주문 인증은 제공하지 않습니다. 브라우저 데이터를 지우면 계정도 사라집니다. 로그인 상태는 해당 탭 세션에서 최대 8시간 저장합니다.

카카오 로그인은 별도 Node 서버가 실제 설정된 경우에만 선택할 수 있습니다. GitHub Pages 자체는 인증 서버를 실행하지 않습니다. 설정 방법은 [AUTH_AND_MOBILITY.md](AUTH_AND_MOBILITY.md)를 참고하세요.

pay 버튼은 당도 안의 결제 페이지를 엽니다. 지점, 주문 내용, 금액과 카카오페이 결제수단을 표시하며 실제 승인 연결 전에는 결제 버튼이 비활성화됩니다. 설정에서 지점별 사은품을 등록하면 그 지점의 목록·상세·결제 페이지에 표시됩니다. [PAYMENTS.md](PAYMENTS.md)

카카오톡 공유는 사용자가 수신자를 선택하는 공식 JavaScript SDK 기능입니다. 자동 알림톡이나 임의 친구 메시지 발송과는 별도입니다. [KAKAO_MESSAGES.md](KAKAO_MESSAGES.md)

## 실행 및 검증

```sh
npm ci
npm run dev
npm test
npm run build
```

공개 지도/장소 API와 선택된 GPS만 사용하며 위치 이력은 저장하지 않습니다. AI 모델은 사용자가 추천 요청을 실행할 때 브라우저에서 로드됩니다. 식당별 대기시간과 예약 가능 여부는 현재 제공하지 않습니다.

카카오 공식 앱이나 제휴 서비스가 아닌 독립 프로젝트입니다.
